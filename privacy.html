Política de Privacidade do claude-drive

O claude-drive é um aplicativo de uso pessoal e interno da ARCLAB MEDIA LTDA, usado apenas pelo próprio proprietário.

Dados acessados

O aplicativo acessa somente os arquivos do Google Drive, Google Docs e Google Sheets da conta do proprietário, e apenas depois da autorização dele.

Uso dos dados

Os dados são usados exclusivamente para ler, criar e organizar arquivos do proprietário. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Armazenamento

Os tokens de acesso ficam salvos apenas no computador do proprietário. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
